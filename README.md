# 🌻 Plants vs Zombies: Console Edition 🧟
## 💻 Версия Python и библиотек
* **Python:** 3.10+
* **Библиотеки:** Сторонние библиотеки не используются. Только стандартные модули: `json`, `copy`, `abc`, `random`.

## 🚀 Инструкция по запуску
1. Склонируйте репозиторий на локальный компьютер:
   ```bash
   git clone https://github.com/Telpu3/Plants-vs-Zombies.git
2. Откройте терминал в папке с проектом.
3. Запустите главный файл

## 🎮 Краткая справка (Как играть)
После запуска вы увидите игровое поле 10x10 и главное меню:
Управление базой: просмотр статуса базы и создание новых растений.
Управление юнитом: выбор конкретного растения, его перемещение по координатам и использование способностей.
Загрузить игру: восстановление счетчика созданных юнитов из JSON-файла.
Сохранить игру: сохранение счетчика созданных юнитов в JSON-файл.
Новый зомби: спавн нового зомби в случайном месте поля.
Конец хода: зомби делают шаг влево. Если на пути стоит растение — они его атакуют.
Закончить игру: выход.
## 🏗️ Структура проекта
1. main.py — точка входа, консольное меню.
2. game.py — класс игрового поля.
3. units.py — базовый класс юнита и все его наследники.
4. base.py — класс базы.
5. landscape.py — классы ландшафта, нейтральных объектов и перегрузка операторов.
6. task4.py — счетчик экземпляров.
